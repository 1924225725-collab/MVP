## 三、关键决策/约定（不可违反）

- **Chapter/Story 都是软边界**：不阻止跨边界取上下文
- **不推翻 A1/A2/A3/B1**（已冻结为底层能力）
- **不接入 Audio/Vision**（Audio 已判本地 DSP 到瓶颈暂停）
- 不简单追求事件变长——要**事件完整性** + **真实高光召回** + **避免过度合并**
- 不为省 Token 跳过关键真实验证；不为让测试过而调阈值/时长
- 小步走、最小修改、不重构
