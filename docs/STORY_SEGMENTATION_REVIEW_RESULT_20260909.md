## 修改建议

### 方案A：调整 prompt 提示词
在 Story 划分提示词中增加：
```
"如果两个事件发生在同一场景、涉及同一对象或存在因果关联，应合并为同一 Story"
```

### 方案B：后处理合并规则
在 AI 输出后，添加规则：
```
if story_A.end_time 与 story_B.start_time 间隔 < 5分钟:
    if 主题关键词重叠 > 30%:
        merge(story_A, story_B)
```

### 方案C：人工微调
对于 ch-03 这类边界情况，允许人工合并相邻 Story。
