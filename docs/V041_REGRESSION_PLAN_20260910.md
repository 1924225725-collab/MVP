## 五、验收标准

### 硬性指标

| 指标 | 阈值 | 说明 |
|------|------|------|
| Story ID 覆盖率 | ≥ 95% | 允许少量 __unknown__ |
| ≤28s 碎片率 | ≤ B1 基线 | 不应比 B1 更碎 |
| 跨 Story 合并 | ≤ 10% 事件 | 大多数合并应发生在同 Story 内 |
| 单视频成本 | ¥0.2~0.6 | 精细模式 |

### 软性指标（人工复核）

- [ ] 每个 Story 内的事件具有主题连贯性
- [ ] 跨 Story 边界处的事件有明确的内容转换
- [ ] 未发现明显的内容断裂（同一完整事件被错误拆分）
