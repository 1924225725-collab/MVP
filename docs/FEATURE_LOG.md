## 一、视频转文字稿（ASR）

**v0.1（2026-09-08）** 首次可用
- 把视频文件夹里的 MP4 自动转成带时间戳的文字稿：自动扫描 → 提取音频 → 语音识别 → 输出逐句文字稿
- 语音识别在本地 CPU 运行，不用联网、零成本
- 实测：6.5 分钟视频识别 41 句，时间戳准确

**已知短板（至今未变）**
- 嘈杂人声有错字，人名识别最差——这是后续「文本纠错」功能的由来

## 二、高光候选生成（召回）

这是整个产品变化最剧烈的功能，经历了三次策略转向：

**v0.2（2026-09-08）** 整篇直喂
- 把整场文字稿一次性交给 AI，让它直接挑高光
- 问题：长文本只看前半段就下结论，**前半段偏置**——后面的爆点永远轮不到

**v0.3 Phase 1（2026-09-09）** 全覆盖扫描
- 改为本地信号扫描：每一分钟打一个「热度分」，哪里词密集、哪里有强信号词（卧槽/炸了/笑死等）哪里热
- 热的地方切成小区块细看，冷的地方切成大区块粗看，保证**时间轴 100% 覆盖，一个区块都不漏**
- 实测：51 分钟直播 14 个区块，热区集中在 29-35 和 47-51 分钟——前半段偏置**结构性解决**

**v0.3.1（2026-09-09）** 召回优先
- 背景：真实测试 AI 输出 0 个高光，人工复盘发现该场明明有多个明显爆点——问题不是覆盖不足，是**第一轮就把候选掐死了**
- 改为「宁多勿少」：每个区块至少 1 个候选、拿不准就先收进来、第一轮不判生死
- 新增三类高光分类：**事件型**（有完整故事）/ **情绪型**（主播爆发）/ **梗型**（一句话成名）
- 实测：候选池从 1 个涨到 36 个，上一版漏掉的爆点全部召回

**v0.3.2（2026-09-09）** 发现视角换脑子
- 海选提示词同步升级：每个候选先自问「**一个不认识主播的新用户刷到开头 3 秒，为什么会停下来？**」——找的是钩子（误会/悬念/强反差/离谱事件），不是「这段讲了啥」
- 新增「假高光」警惕清单：普通失误、普通展示、单纯惊讶、普通评价——表面热闹，通常不是真爆点（海选仍不判生死，只是别把它们当首选，过滤权留给复审）

## 三、高光复审与淘汰

**v0.3 Phase 2（2026-09-09）** 严格淘汰制
- 第二轮 AI 以「资深直播短视频运营」身份复审每个候选，不合格直接毙掉并给出拒绝理由
- 首次真实测试：唯一候选被毙，全场 0 推荐——淘汰机制是真在干活，但**过严**

**v0.3.1（2026-09-09）** 分级替代生死
- 复审从「推荐/毙掉」二元制改为 **A/B/C/D 四级**：A 强烈推荐剪 / B 值得测试 / C 备用素材 / D 淘汰
- 新增**零输出禁令**：除非全场候选都低于 4 分且无任何情绪节点和独立成片可能，否则不允许输出 0 个；代码层还有兜底（全灭时最佳候选 ≥4 分强制保留一个 C 级）
- 实测：36 候选 → 7 个 A 级 / 19 个 B 级 / 10 个 C 级，0 淘汰

**v0.3.2（2026-09-09）** 五级分级 + 负面清单封顶
- A/B/C/D → **S/A/B/C/D 五级**：S 爆款候选（≥9.0）/ A 强推荐（≥8.0）/ B 测试素材（≥6.0）/ C 备用素材（≥5.0）/ D 淘汰
- 新增「不值得剪」**负面清单**（普通失误 / 普通展示 / 单纯惊讶 / 依赖上下文 / 普通评价）：复审命中任一就填 negative_flags，**本地强制封顶 B 级**——AI 说破天也进不了 S/A，「事故 = 高光」被结构性杜绝（只降不升，本来就是 C/D 的不动）
- 每个候选复审必答两句：**为什么值得剪**（陌生人为何停留 + 核心传播点，写不出来 = 可能不值得剪）+ **最大风险**（必须诚实指出短板，禁止写「无」）
- 复审不再给总分和等级，只打五个子分「零件」，等级由本地组装——AI 不能靠一句漂亮理由把普通失误捧上精品位

## 四、漏检质检

**v0.3.1（2026-09-09）** 新增功能
- 复审之后加一道独立的「质检 AI」：它不找高光，只回答一个问题——**「有没有明显爆点被漏掉了？」**
- 发现可疑区块就用更宽的标准重新扫一遍，新候选去重后并入候选池
- 实测：真查出 2 个漏检区块（理由具体：「信号分 11 全场最高但候选没覆盖」），重扫补回 3 个候选——不是摆设

## 五、评分标准

**v0.3 Phase 2** 初版权重
- 传播 30 / 情绪 25 / 冲突反转 20 / 独立观看 15 / 内容 10（2026-09-09 规范 v1.0 定稿，D-012）

**v0.3.1** 权重 v2（D-020）
- 传播 30 / 情绪 25 / **主播个人特色 15** / **争议讨论 15** / 独立成片 10 / 内容 5
- 变化逻辑：直播不是纪录片，很多爆款来自人物反应而不是完整故事

**v0.3.2（2026-09-09）** 评分模型 v3（D-022）——从「内容好不好」转向「能不能火」
- 背景：人工复盘发现 AI 打分还是在评价「这件事大不大、主播惊不惊讶」——饮料粉洒出来、军粮份量少这种事故被评高分；而部分 B 级候选（误会/反差/有记忆点）反而更适合剪。问题根源：**评分维度里没有「三秒吸引力」和「反差」，全是内容维度**
- 变成什么样：
  - 五维全换：**三秒吸引力 30 / 反差意外 25 / 人物表现力 20 / 独立成片 15 / 事件完整度 10**（删除情绪冲击/争议讨论这类「热闹度」维度——惊讶不等于高光）
  - 复审 AI 只打五个子分（1-10），总分本地按权重加权、等级本地按分数线定：分数来源全程可审计，AI 也没有「先给漂亮理由、再顺手打 9 分」的空间
  - 案例校准写进提示词：黄腐鸡误当咖啡（误会+反差）该高分；军粮「像纸盒子」、罐头「像指甲盖」（具体比喻 = 天然标题/记忆点）该高分；饮料粉洒出来、「哇好少」（纯事故/纯惊讶）不给高分
  - 每个候选带「五维判决书」：三秒吸引力 8 分 / 反差意外 9 分……剪之前先看它到底赢在哪、输在哪

## 八、成本控制

**v0.1（2026-09-08）** 成本四闸门
- 单次输入 6000 字截断 / 输出 1500 token 上限 / 打印字数 / 成本报表

**v0.3 Phase 2（2026-09-09）** 预算三模式
- 快速 / 标准 / 精细三档预算，超预算自动三级降级（先粗切 → 再限候选 → 提示继续）
- 运行前可预估总 token 和费用

**v0.3.1（2026-09-09）** 策略转向（D-021）
- 精细模式预算 5 万 → 8 万：**不再压缩成本换准确率**——用户付费的是准确率，不是省几分钱
- 实测：51 分钟直播精细模式全程无降级，一次分析 ¥0.19

## 十、使用界面

**v0.2 ~ v0.2.2（2026-09-08 ~ 09）**
- 命令行之外新增网页版：四步任务清单实时刷新、总进度条、运行日志直接进网页
- API Key 在网页侧边栏填写，不用设环境变量
- 双击 `start_webui.bat` 即可启动

**v0.3.2 第一步（2026-09-09）** 网页版切到 v2 分析流程
- 从什么样：网页版点「开始分析」走的还是 v0.2 旧流程（整篇直喂、无类型/模式设置、旧版卡片），v0.3 全部新功能只能用命令行
- 变成什么样：「开始分析」直接走 v2 流程（海选→质检→复审）；侧边栏三设置（直播类型/分析模式/数量模式）；文字稿与 AI 分析拆两步——识别过的稿子换设置即可重跑，不重复烧 ASR 时间；运行前显示预算预估（时长/预计 token/预计费用，超预算提示降级）；结果改 A/B/C 分级卡片（三类高光/置信度/剪辑建议）+ AI 分析报告四字段 + 被拒候选（带拒绝理由）+ 完整 JSON 下载
- 为什么：判断链路 v0.3.1 已过真实 API 验证，UI 停在 v0.2 成为瓶颈；用户要做多视频精准度测试，必须脱离命令行；识别/分析拆两步让同一场直播能用不同类型和模式反复对照（精准度测试刚需）
- 效果：语法编译通过、服务启动正常，待真实视频实测

**v0.3.2 第二步（2026-09-09）** 结果卡片升级：五级徽章 + 五维判决书
- 卡片顶部按等级出四色徽章：🚀 S 级爆款候选 / 🌟 A 级强推荐 / ✅ B 级测试素材 / 📦 C 级备用素材
- 每张卡新增「五维判决书」进度条——把分数拆开给用户看：三秒吸引力 8分 / 反差意外 9分 / 人物表现力 7分……分数怎么来的不再是个黑盒
- 命中「不值得剪」清单的卡片黄条警示「已封顶 B 级，仅作测试素材」；每张卡显示 AI 承认的最大风险
- 为什么：判断视角升级后，用户需要能逐维审计 AI 的判断，也方便在测试时快速挑出「AI 判错维度的案例」反馈给开发
